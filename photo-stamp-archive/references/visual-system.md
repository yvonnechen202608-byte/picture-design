# 视觉系统：摄影现场 × 旅行刻印

这是从多张双栏旅行图像中抽象出的原创生成系统。它保留视觉关系和媒材逻辑，不保留任何一张参考图的具体地点、轮廓或排列。

## 1. 核心叙事

一张图里有两种时间：

- **左侧是现在时**：人眼实际看到的现场，光线、天气、比例和质地都可信。
- **右侧是记忆时**：现场被压缩成一枚小小的纪念印，只留下最能唤回记忆的轮廓、结构和色彩关系。
- **纸面是距离**：右侧 62–76% 的空白让印记像被归档的小标本，不是布置未完的空洞。

## 2. 版式骨架

### 默认竖版

- 画布比例约 3:4，可在 0.70–0.76 宽高比内调整。
- 左侧摄影栏占宽 49–53%，右侧纸面占 47–51%；分界是一条干净竖线，无中缝、投影或框线。
- 左侧照片全出血。主体可大幅裁切，但不能丢失最关键的完整结构。
- 右侧印记落在画布高度约 63–88% 之间。方形或竖向主体的印面宽度为右栏的 55–72%；横向风景印可占 76–92%，但高度依然克制。
- 印记与标签组整体距右、下边界约 7–11%；文字与印面左边缘对齐。

### 左侧摄影

- 优先用端正而有张力的视角：建筑突出垂直、桥梁突出跨度，山峰保留山脊，沙丘保留明暗分界，海岸保留地平线和岩石节奏。
- 天空、水面、山谷或夜色可成为照片内的大留白，与右侧纸面形成响应。
- 自然色彩、中等反差、略微柔化的高光和很轻的胶片颗粒即可。不做 HDR、霭虹蒸汽波、重度褪色或老照片划痕。
- 必要的小人、车辆或灯光可作比例线索，但不能把主题变成拥挤的纪实场面。

## 3. 识别骨架算法

生成印记前，先找出主体的 2–4 个“丢了就不再是它”的特征：

1. **主轮廓**：最高峰的起伏、雕像的坐姿、树冠外形、容器的口沿。
2. **结构线**：桥塔与缆索、摩天楼高低次序、机器关节、人物手势。
3. **空间关系**：山与谷、树与远山、主楼与低矮天际线、物体与它的阴影。
4. **色彩锚点**：桥的锈红、海的青蓝、夜塔的暖黄、沙的赭金。

把这些特征组成一句话，例如：“保留两座桥塔的高度差、主缆的抛物线和水面横线；删除车流、人群和建筑碎片。”印记只服务这句话。

## 4. 印刷语法

- 媒材是橡皮章、凸版木刻、粗网丝印和旧式图录网点的混合；整体平面，不做浮雕厚度。
- 先用大色块建立剪影，再用少量密集短线、网点和留白描述岩石、海浪、楼群或金属。
- 边缘有干墨、断线、纸纤维和轻微套色错位；破损要随机而节制，不是统一的数字噪点蒙版。
- 阴影依靠墨色覆盖和纸面留白，不用平滑渐变、光泽反射、真实镜头景深或数字柔光。
- 建筑/城市/器物的印面可有近似方形的粗糙外框；地貌/海岸/植物优先让地平线、山脚或油墨毛边自然结束画面。

## 5. 固定色彩骨架

右侧纸面固定为暖象牙色，印记每张只从下列角色中选 2–3 种。十六进制值是方向，色彩关系更重要。

| 角色 | 建议色 | 用法 |
| --- | --- | --- |
| 暖象牙纸 | `#F1EEE4` | 右栏底色；带细微纸纤维，不是纯白 |
| 石板蓝 | `#546F7D` | 山岩、远山、天际线、冷色主墨 |
| 深海蓝 | `#294A59` | 夜景、建筑暗部、强轮廓 |
| 海水青 | `#6E9290` | 水面、湿岩、冷色调和 |
| 矿物赭 | `#A85643` | 桥梁、砖石、暖色建筑、小面积主色 |
| 沙岩赭 | `#B69554` | 沙丘、草地、日照、次级油墨 |
| 苔藓橄榄 | `#7D8056` | 山坡、植被、老铜青绿 |
| 炭灰 | `#414846` | 岩石、文字、最深结构；避免纯黑 |

用色逻辑：一种深墨建结构，一种主题墨建色彩记忆，可选第三种浅墨建空气或远景。不在同一枚印中使用全部色板。

## 6. 题材转译

| 题材 | 优先保留 | 印面倾向 |
| --- | --- | --- |
| 山峰/山谷 | 山脊起伏、主峰比例、河道 | 石板蓝 + 沙岩赭，无框横向毛边 |
| 桥梁/工程 | 桥塔、跨度、缆索/桡架 | 矿物赭 + 石板蓝，粗糙方框 |
| 城市/建筑 | 高低节奏、地标结构、云层或广场 | 深海蓝 + 一个暖色锦标，方框 |
| 海岸/湖泊 | 地平线、岩石节奏、远岛 | 海水青 + 炭灰，宽幅无框 |
| 沙丘/雪地 | 曲线山脊、明暗分界、尺度参照 | 沙岩赭 + 石板蓝/炭灰，柔边印面 |
| 人物/动物 | 姿态、轮廓、标志性配件或毛色 | 主色 + 炭灰，如旧式图鉴小肖像 |
| 器物/食物 | 外轮廓、功能结构、一个材质特征 | 两色标本印，规整物件可带框 |
| 抽象概念 | 一个可观察的物理隐喻及其空间关系 | 先成立一张真实现场照片，再将同一隐喻刻印化 |

## 7. 纸张与文字

- 纸张是中性暖白，可见极细纤维、偶发浅斑和轻微不均色温；不可有强烈折痕、破边、咖啡渍或深色四角。
- 标签是打字机等宽衬线与旧式活字的混合；稍有跳字和墨量不均，但仍清晰可读。
- 标题比描述词略大或略深，但整组文字只是印记的索引，不得成为视觉主角。
- 默认使用英文短标签，是为了保留精简的旅行档案气质，而不是伪造具体地点记录。

## 8. 生成前自检

- 左侧是否是一张可信的照片，而不是另一种插画？
- 右侧是否至少有约三分之二的空白？
- 印记是否与左侧共享同一识别骨架，又明显不是照片缩略图？
- 是否只用了 2–3 层墨色，并留出纸白？
- 印记的外框是否服务题材，而不是每张机械复制？
- 标签是否简短、可读、左对齐，没有虚构信息？
- 是否删掉了与主题无关的明信片套路和装饰？
