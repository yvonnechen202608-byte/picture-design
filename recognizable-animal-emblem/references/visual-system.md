# 高辨识动物面徽视觉系统

这套系统来自多张“动物现实形态 → 平面编辑肖像”的共同规律。它保存的是辨识优先级、减法程度、配色角色、留白、媒材与字体气质，不保存任何一张参考图的具体动物、色块分割、视角、标题或排布。

## 1. 设计命题

目标不是“画得越少越高级”，而是“用尽可能少的平面信息，保住尽可能强的面部辨识”。

- 第一眼应认出动物大类或物种；有宠物参考时，还应认出个体。
- 第二眼才读到有机几何、负形、节奏线和编辑式留白。
- “更写实”指头颅、脸部比例、特征位置和神态准确；不指写实毛发、光照、体积阴影和照片材质。
- “抽象”指将体积和表面归纳为有限色面；不得删掉识别物种所必需的结构。

## 2. 硬性不变量

每张图同时满足：

- 最终是一张独立插画或单个资产，不是照片对照、设计过程图、分屏、色卡或样机。
- 只有一个动物主角，只展示面部、头部或必要的少量颈肩；不讲述完整环境故事。
- 动物的外轮廓、头部比例与 3–5 个核心标志准确，缩小到徽章大小仍可辨识。
- 主要由 7–18 个有机形状组构成；一组胡须、羽冠细线或简化羽片可算一个节奏组，但不得扩张为密集纹理。
- 可见颜色通常为 4–6 类：暖纸色、深色锚点、骨白、一个灰褐或灰蓝中间色，以及最多一个主题点睛色。
- 平面哑光色面为主，仅有极轻微的纸本印刷或薄水粉触感；无摄影纹理、无三维光影、无发光、无照片级细节。
- 造型有生物感，不是纯几何对称 logo；视觉安静、克制、有展览图鉴和编辑插画气质。

## 3. 辨识骨架

按以下优先级从真实动物或参考图中提取信息：

1. **外轮廓**：脸形，头顶、两颊与下颌的宽窄，耳、角、喙、羽冠的角度和长度。
2. **地标几何**：眼距与眼高，眉眼关系，口鼻或喙相对面宽的比例，中轴是否倾斜。
3. **招牌色块**：额头火焰纹、眼罩、口鼻白斑、脸颊圆斑、耳尖、颈下色块等。只保留真正有识别力的部分。
4. **独特附件**：铃铛、项圈、胡须、羽冠或角上的缺口；只在它确实有助于辨识时保留一项。
5. **微细节**：单根毛发、羽枝、皮肤纹理、鼻头湿润或环境反光；默认删除。

将轮廓与五官作为结构实物，不要为了形式感任意滑动它们。不强求左右完全对称；稍微不对称的头倾、耳位或眼神往往是个体感的来源。

识别测试：

- 在约 64 px 小图下，不借助文字仍可认出动物大类。
- 转为灰度或只看外轮廓时，不与常见其他物种混淆。
- 如去掉某个色块就无法认出个体，它是辨识锚点；如去掉后没有影响，可继续删减。

## 4. 形状与平面层级

建议的形状配额：

- `主轮廓 1–3 组`：头颅、脸部主体和必要的颈肩；
- `特征色面 3–8 组`：耳角、眼罩、脸颊、口鼻、喙或招牌斑纹；
- `五官 2–4 组`：眼、鼻、口的最少必要信息；
- `节奏组 0–1 组`：胡须、羽冠放射线、少量羽片或地面短线；
- `个体附件 0–1 组`：铃铛、项圈或其他真正具有识别力的小物。

用形状本身交代轮廓，少用外描边。五官可比其他部位多一层细度，例如保留瞳孔和一个极小高光，但不得画成湿润玻璃眼或写实 3D 眼球。额头、两颊、口鼻和颈部可有 2–4 个层叠色面，但不使用渐变造型。

## 5. 配色系统

以下色值是方向，不是必须逐项照搬的色卡：

- 纸面：暖象牙 `#F4F0E9`、浅骨纸 `#EFE8DE`；
- 深色锚点：炭灰 `#2E302F`、深蓝炭灰 `#2E3B40`，避免纯黑；
- 浅色结构：骨白 `#DED7CC`、燕麦米 `#CFC4B3`；
- 中间色：灰褐 `#999388`、雾蓝灰 `#73868D`；
- 生物点睛色择一：灰珊瑚 `#E17868`、砂金 `#C5A15D`、烟蓝 `#6C8795`、深苔绿 `#29483F`。

配色关系：

- 编辑卡片中，纸面通常占画布可见面积的 65%–85%；主体小而对比清楚。
- 炭灰与骨白建立识别，灰褐或灰蓝转折体面，点睛色承担物种特征或主题隐喻。
- 若动物的标志色是识别核心，将它映射到最接近的低饱和色；该色可成为主体大色块，但不新增多种饱和色。
- 所有颜色都略偏暖、灰和哑光；禁止荧光色、高饱和彩虹配色、纯黑纯白和金属或珠光渐变。

## 6. 构图模式

### 编辑卡片（默认）

- 默认竖幅 `4:5`；用户指定其他比例时，保留“小主体 + 大留白 + 独立小标题”的关系。
- 面孔或头颈部通常占画布宽度约 35%–55%、高度约 25%–45%，光学居中或略高；耳、角、长喙或羽冠可越出这个参考范围。
- 正面、轻微四分之三侧面或明确侧面都可以，选最能体现物种标志的角度；不为了对称强行正面化。
- 标题放在底部左侧或底部中央，与主体保持显著距离。标题是小声注解，不是海报主角。
- 不添加段落、次标题、边框、色块底板、装饰记号或背景道具。

### 徽章 / 贴纸 / 头像资产

- 默认正方形 `1:1`；如工具支持，可生成透明背景 PNG，否则使用同一暖象牙底。
- 头像占画布约 65%–80%，轮廓尽量完整，尖角、长耳、胡须、喙和羽冠与裁切边缘保留安全距离。
- 默认无文字、无环形字、无阴影和无模拟徽章底托。当用户要求实体徽章效果图时，再添加具体工艺。
- 为刀模或贴纸轮廓保留一个连续可读的外形，但内部可用负形和独立色面；不得因此变成工业矢量 logo。

## 7. 媒材与边缘

成图像精简的纸上水粉、丝网印刷与剪纸形状的交界：

- 色块平滑但不是纯数字填充，内部可见极轻微、大尺度的浓淡偏差；
- 边缘清楚、圆钝、略有手工偏移，但不是毛糙涢水边、油画笔触或锯齿像素边；
- 只在胡须、口缝、眼睑或羽冠需要时使用纤细断线，其余由色块相互切分；
- 无方向性真实光源，深浅色面是结构归纳，不是阴影和高光；
- 纸纹只能被隐约感到，不制造污渍、折痕、噪点、复古棕黄或重度旧化。

## 8. 字体气质

- 小字号、纤细至常规字重、笔画粗细对比高、比例偏窄长的编辑衬线字；英文有现代时尚杂志的冷静，中文有清瘦宋体的人文感。
- 字色使用深蓝炭灰 `#2E3B40`，可略浅于主体最深色；英文字距稍松，不使用全大写阵列。
- 标题只有一层，一行为佳；不使用粗黑无衬线、手写体、花体、气泡字、震颤排版、文字轮廓线、投影或渐变。
- 文字与图像之间必须有大段空白，像图鉴或小型展签，不像广告标语。

## 9. 非动物主题的转译

当输入是情绪、概念、产品、地点或故事时：

1. 提取一个核心状态，例如警觉、耐心、展开、隐藏、归巢或平衡。
2. 选择一种面部形态或习性真正支持该状态的动物；避免总是使用最常见的陈词滥调动物象征。
3. 主题仅影响一个形式变量：一块点睛色、一处负形缺口、一组线性附件或一个头部姿态。
4. 不在动物周围堆放道具、风景、图标或文字解释主题。标题可命名主题，但插画必须自身成立。

## 10. 参考图与原创性

- 普通风格参考只贡献高层规律：识别优先级、有机平面抽象、暖纸色、限定色、留白和小标题气质。
- 个体参考可贡献可核对的生物特征，但新插画必须重新组织视角、轮廓简化、色块边界和版式。
- 不复制参考中的左右或上下分屏、照片裁切、动物轮廓、色块数量与位置、标题、细线走向、底部横线或精确留白比例。
- 不提及、模仿或冒充具体艺术家或品牌；使用可观察的形状、色彩、媒材和版式语言描述。
- 除非用户明确要求对照页，最终图中不出现参考照片、缩略图、色卡、过程标注、Logo 或水印。

## 12. 生成后检查

按顺序检查：

- **识别**：缩小到徽章尺寸时，是否先认出动物？物种、脸型和标志斑纹是否准确？
- **抽象层级**：是否由有限色面归纳体积，同时没有变成不可辨的形状练习或 logo？
- **面部焦点**：是否只有面部、头部或少量颈肩，没有被身体和环境分散？
- **配色**：是否守住暖纸、炭灰、骨白、灰中间色和单一低饱和点睛色？
- **留白与排版**：编辑模式是否有明显大留白与一行安静小标题？资产模式是否为裁切保留完整外轮廓？
- **媒材**：是否平面哑光、略有纸本手感，却不像过度平滑的矢量、照片或 3D 渲染？
- **原创性**：是否与参考同属一个视觉家族，却没有重演任何一张的动物轮廓、色块分割或精确版式？
- **文字**：如有，是否逐字准确、位于独立留白且没有喧宾夺主？

任一硬性不变量失败时，只修改对应问题；不在迭代时新增动物、场景、颜色或文字层级。
