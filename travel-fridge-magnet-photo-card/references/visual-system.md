# 视觉系统

这套规则来自一组旅行摄影卡片的共同设计语法，只保留抽象规律，不保留任何单张参考图的具体内容。

## 固定骨架

- 画布：竖版 3:4；默认 1080 × 1440 px。
- 分区：上、下各占 50%，在画面中线硬切；不用渐变、羽化、描边或过渡带。
- 上半部：单一纯色、中央小型贴纸、一行标签，其余全部留白。
- 下半部：摄影源等比放大并居中裁切为横向 3:2 区域。允许调整裁切焦点，不允许生成式重绘或调色。
- 视觉重心：上半部轻、静、疏；下半部真实、信息密度高。二者靠同源色彩和同一主体建立联系。

## 配色

从摄影源最有记忆点的大面积颜色中选一个主色，再映射到以下色彩家族。允许为协调照片在明度与饱和度上小幅移动，但不要建立一套无关的新配色。

- 玫瑰粉：约 `#F496A8`
- 奶油黄：约 `#FCDE7F`
- 鼠尾草绿：约 `#C6D2A8`
- 明信片蓝：约 `#3677CC`
- 夜色海军蓝：约 `#1A203E`
- 杏仁蜜桃：约 `#FCD491`

选择规则：

- 优先跟随照片里的墙面、天空、水面、舞台、店招、车辆、植被或夜色等大面积环境色。
- 背景必须干净、单一、中高纯度；浅色可以柔和但不能灰脏，深色必须保持色相可辨。
- 贴纸内部使用从照片归纳出的 4–7 色小色板；轮廓和标志色比微小写实色差更重要。
- 浅背景标签用暖深棕 `#5B4938`；深背景标签用暖象牙白 `#F4EBD7`。不用纯黑或刺眼纯白。

## 贴纸插画

- 主体宽度通常占全画布 24–42%，宁小勿大；宽建筑可接近上限，竖向地标使用下限。
- 贴纸视觉中心约在上半区高度的 44%；文字中心约在上半区高度的 80%。贴纸与文字之间保持清晰空气感。
- 保留一个闭合、可一眼识别的外轮廓，以及 2–5 个标志性特征。透视可以简化，但不得把地标改成另一栋建筑或把物种改错。
- 插画语言：原创旅行纪念品图标、平面手绘与轻矢量之间、细线勾勒、局部低密度纸墨或彩铅颗粒、哑光印刷感、适度简化。
- 最终白色或暖白色模切边和向右下方的柔和投影由合成脚本统一添加。生成阶段不要画底板、边框或假透明棋盘格。
- 不做塑料高光、厚重倒角、强烈透视、写实照片抠图、复杂背景场景或大型徽章。

### 不同主体如何提炼

| 输入主题 | 优先保留 | 省略什么 |
|---|---|---|
| 建筑/城市 | 屋顶线、门窗节奏、塔楼、拱门、立面色块 | 路人、车流、广告杂讯、所有窗格细节 |
| 风景 | 独特天际线、树形、水岸、山体层次、倒影 | 零碎枝叶、远处小物、云层噪声 |
| 人物/活动 | 人数、主要姿态、服装主色、舞台或空间轮廓 | 面部写实、无关观众、微小道具 |
| 动物 | 物种、毛色块、耳眼特征、动作关系 | 写实毛发、笼舍杂物、重复背景 |
| 食物/店铺 | 招牌轮廓、门面结构、代表性器具或食物 | 小菜单、价格、不可控的小字 |
| 车辆/物件 | 侧影、轮组或把手、独特结构、主色 | 机械微件、品牌小字、环境杂物 |

人物和动物只有在它们是记忆点时才进入贴纸；不要为了“热闹”自行添加。

## 字体与标签

- 仅一行，水平居中，位于贴纸下方，不压住主体。
- 首选 American Typewriter Regular 一类温和、细瘦、略带旧旅行卡气质的打字机衬线；后备 Baskerville 或 Palatino Regular。
- 字重 Regular，字号约为画布宽度的 3.5–4.0%，轻微字距，不加粗、不全大写、不使用花体或手写体。
- 典型结构为 `Place, YYYY`，但用户给出的精确文本优先。不要擅自补逗号、改拼写或编造年份。
- 贴纸内部默认不生成任何文字。若店招文字确实是识别核心，只能使用用户明确提供的短文本，并逐字核对；无法保证正确时改用无字色块和结构暗示。

## 原创性

同一视觉家族由“50/50 硬切 + 单色留白 + 小型模切贴纸 + 一行旧式衬线标签 + 原照片”建立，而不是由某个特定图标建立。新图必须重新选择轮廓、特征、色块与裁切，不能套用参考图里的熊猫、钟楼、天际线、舞台或店铺构图。
