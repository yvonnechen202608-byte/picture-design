# 静默水粉符号视觉系统

这套系统来自多张“现实照片 → 极简插画”的共同规律。它保存的是抽象方法、色彩关系、构图重心与材料气质，不保存任何一张参考图的具体建筑、色块位置或画面骨架。

## 1. 硬性不变量

每张图同时满足以下条件：

- 一张独立插画，而不是照片对照、过程图、分屏、样机或海报展示页。
- 暖象牙白或浅米色纸面占绝大部分画布，背景连续、安静、未经装饰。
- 一个清晰但高度概括的主题符号；观者先读到抽象构成，再从一个记忆锚点认出主题。
- 主体视觉占幅通常为画布的 25%–40%，至少约 60% 的区域保持呼吸感。主体光学居中或略低，不能顶满画面。
- 8–15 个主要形状组；一列重复竖线、一排短横或一圈断续弧线分别可算一个节奏组，但不得演变成密集细节。
- 3–5 种总色彩形成克制关系：暖纸色、一个深色锚点、一个冷灰或灰蓝主色、一个浅石色，必要时加一个很小的暖色点睛。
- 扁平、哑光、薄层水粉与纸本拼贴之间的手感；边缘略有毛涩和偏差，颜色内部轻微不匀。
- 没有摄影透视、真实光影、阴影塑形、复杂渐变、精细描边、写实材质或环境铺陈。

用户明确要求的内容、比例和文字可以改变；上述视觉关系不改变。

## 2. 信息压缩法

不要从“画出完整对象”开始，而要从“留下哪一个视觉记忆”开始。

1. 用一句话概括主题最独特的辨识点，例如“被缺口打断的圆”“向两侧展开的扁平顶盖”“高低错落的几根竖条”。
2. 选择一个视觉动作：围合、堆叠、穿越、倾斜、悬浮、环绕、展开或承托。
3. 只保留一个记忆锚点。其余信息即使真实存在，也可以删除、断开、错位或合并。
4. 让对象从三维名词变成二维关系：大与小、长与短、疏与密、重与轻、围合与缺口、上浮与落地。

推荐的形状配额：

- `主形 1–3 组`：承担剪影和最大色块；
- `支撑形 3–6 组`：提供重心、底座或方向；
- `节奏 1–2 组`：短横、竖线、断弧或小矩形的重复；
- `点睛 1 组`：一个很小的砖红、赭黄、暗绿或珊瑚色块。

形状之间应有可见的纸色缝隙。允许不闭合、不对齐、断裂和轻微失衡；不要为了说明对象而把所有结构连接起来。

## 3. 构图规律

- 默认竖幅 4:5；横向主题也应被包裹在大幅纸面中，而不是裁满。
- 主体通常落在画面中下部，顶部留白略多于底部。可以用一条短基线、一个浅色底座或悬浮关系使其稳定。
- 正面化和平面化优先。近似对称可以用来形成图腾感，但必须保留手工的不等宽、不等距和轻微偏心。
- 用“一个主轮廓 + 一个反向或横向节奏”建立张力。例如圆弧配直线、竖塔配低矮基座、重色块配细线。
- 留白是主动形状，不是剩余空间。不要在空白处补云、叶子、颗粒、符号或装饰线。

## 4. 配色系统

色值是方向，不是必须逐项照抄的色卡：

- 纸面：暖象牙 `#F3EBDD` 或浅米纸 `#EEE5D3`；
- 深色锚点：炭灰 `#293437` 或墨蓝灰 `#304047`，避免纯黑；
- 冷静主色：烟灰蓝 `#5F747A`、灰青 `#657B78` 或低饱和苔绿 `#6E784D`；
- 浅中性色：石灰米 `#B9B19D`、雾灰米 `#CEC5B1`；
- 点睛色四选一：赭黄 `#C38D22`、砖红 `#BE4D32`、灰珊瑚 `#CF856E`、深苔绿 `#3F5B48`。

配色关系比具体色号重要：

- 纸面约占可见面积的 65%–80%；
- 主冷色与深色共同承担重量，但不要平均分配；
- 浅中性色负责过渡和呼吸；
- 点睛色通常不超过画布的 1%–3%，只出现一次或作为一个极小组；
- 若主题天然偏暖或偏绿，用相邻的低饱和色替换灰蓝，而不是不断增加颜色；
- 禁止高饱和全彩、荧光色、纯黑纯白强对比和摄影式取色。

## 5. 材料与边缘

画面像在温暖纸张上用略稀的水粉绘制，再带一点手撕纸拼贴的平面感：

- 大色块哑光，局部可见轻微半透明叠色；
- 色块内部允许约 5%–15% 的浓淡波动，但不制造真实材质；
- 边缘轻微参差、圆钝或不完全平行，不能像矢量路径那样锋利完美；
- 轮廓通常由色块自身形成。只有结构确实需要时，才用极少的炭灰细线或断线；
- 纸纹非常轻，只提供材料存在感，不能变成满屏噪点、做旧污渍或扫描颗粒。

## 6. 跨主题转译

- 建筑或物件：保留最独特的轮廓、开口或受力关系，删除零件和表面。
- 人物或动物：保留一个姿态、比例或动作关系；脸、衣纹、毛发和身份细节全部简化。
- 植物或食物：保留生长方向、包裹关系、切面或堆叠方式，不逐片画叶、不描绘配料。
- 景观或城市：保留路径、环形、层级或天际线节奏，把远近压成同一平面。
- 事件或故事：只选择一个最能代表事件的关系，不做多人物连续叙事。
- 情绪或抽象概念：把它转成重量、方向、距离、缺口、围合、失衡或重复，不使用通用表情符号和陈词滥调图标。

若主题脱离建筑，仍然使用同一“安静图腾”语法；不要强行把动物、食物或概念画成建筑。

## 7. 字体气质

参考画面本身没有文字，因此以下是与其视觉气质相容的排版规则，不是假定存在某个具体参考字体。

- 默认无文字。
- 用户明确要求时，只放必要原文，文字量和层级越少越好。
- 使用轻字重、低对比、略有人文感的现代主义无衬线或克制的编辑字体气质；中文应疏朗、清瘦，英文可略加字距。
- 字色使用炭灰或墨蓝灰，不使用纯黑；字号小，位于主体之外的独立留白中。
- 允许非常轻微的手工套印偏差，但不使用夸张手写体、泡泡字、粗黑商业标题或复古做旧字。
- 文字必须准确可读。若生成工具无法可靠呈现原文，明确说明限制并优先交付无字插画版本。

## 8. 原创性边界

- 从参考图学习“抽象到什么程度”和“如何使用留白”，不复制其具体轮廓、色块数量、位置比例、配色对应或上下关系。
- 内容参考图最多贡献一个记忆锚点；其余构图从零重组。
- 不提及、模仿或假冒具体艺术家；用可观察的材料、形状、色彩与构图语言描述风格。
- 不在最终图中放入参考照片、缩略图、色卡、标题、Logo、水印、装饰边框或说明文字，除非用户明确要求其中某项。

## 9. 成图提示词骨架

按任务删减无关字段，但保留可观察约束：

```text
Use case: stylized-concept
Asset type: standalone editorial illustration
Primary request: 将【主题】重新设计为一枚安静的二维视觉象形文字。核心视觉动作是【动作】，唯一记忆锚点是【锚点】。先读作抽象构成，随后才辨认出主题。
Input images: 【如有，逐张注明仅作内容参考、风格参考或编辑目标】
Scene/backdrop: 连续的暖象牙白纸面，没有真实环境和装饰。
Subject: 用 8–15 个主要形状组组织；主形 1–3 组、支撑形 3–6 组、节奏 1–2 组、一个微小点睛色组。允许断裂、省略、错位和不闭合。
Style/medium: 极简手绘水粉与纸本拼贴之间的质感，扁平哑光，略微半透明，色块浓淡轻微不均，边缘温和参差。
Composition/framing: 竖幅 4:5，主体光学居中或略低，只占画布约 25%–40%，至少 60% 大面积未经装饰的留白；平面化、正面化、无摄影纵深。
Lighting/mood: 无方向性写实光影；安静、克制、诗性、现代主义编辑气质。
Color palette: 暖象牙纸色、炭灰或墨蓝灰、烟灰蓝/灰青/苔绿中的一个主色、浅石灰米，以及只占 1%–3% 的单一赭黄/砖红/灰珊瑚点睛；总色彩 3–5 种，低饱和。
Text: 默认无文字；如用户要求，逐字写入准确原文，并遵循小字号、轻字重、疏朗的编辑字体规则。
Constraints: 仅保留一个辨识锚点；删除约 95% 现实细节；重新设计构图，不复制任何参考图。
Avoid: 照片、对照图、分屏、完整场景、窗户砖瓦等微细节、真实材质、透视、阴影塑形、复杂渐变、精细描边、矢量般完美边缘、高饱和全彩、满版构图、标题、Logo、水印、色卡、边框。
```

## 10. 生成后检查

逐项目视判断：

- 第一眼是否是一个抽象构成，而不是完整物体或场景？
- 是否只靠一个记忆锚点让主题被认出？
- 主体是否明显小于画布，周围有至少约 60% 的安静留白？
- 是否只有 3–5 色，并且点睛色真的很小？
- 是否可以数出有限的主要形状组，而不是大量零碎细节？
- 纸面、水粉浓淡和轻微参差是否可见，同时没有做旧噪点？
- 是否无透视、无真实光影、无背景叙事和无海报附加物？
- 是否与参考图属于同一视觉家族，却没有重演任一具体构图？

任一硬性不变量失败时，只修改对应问题；不要在迭代时新增对象、颜色或叙事。
