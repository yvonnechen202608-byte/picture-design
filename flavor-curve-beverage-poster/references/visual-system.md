# 视觉系统：高留白风味曲线 × 写实饮品配方

这套系统从多张饮品拆解图中提炼媒材、色彩角色和信息关系。它保留“写实对象 + 手写标注 + 连续曲线”的视觉家族，不保留任何参考图的具体水果、饮品、线形或坐标。

## 1. 共同视觉规律

- **高调纸面**：背景接近白色但略暖，约 `#FAF9F5`–`#FFFDFC`，没有可见边框、桌面线、场景布景或强纸纹。
- **摄影对象**：材料和饮品是干净的棚拍抠图，柔和正面/侧前方光，真实纹理、少量接触阴影，没有厚重描边。
- **手工编辑层**：文字和曲线统一为深可可棕，约 `#5A342D`–`#6A4035`；笔画细、略有不规则，却清楚稳定。
- **单一动态色源**：每个比例条的填充只取对应材料的代表色。整张图除了食物本色，只保留暖白、深棕和浅灰三个固定角色。
- **大留白与低密度**：背景留白约占画面可见面积的 `55–68%`。对象彼此不拥挤，空白既是层级，也是曲线路径。
- **重心下沉**：饮品是最大对象，落在下部；材料较小，沿上至下形成三次停顿。视线从上方信息块顺着曲线进入主体。
- **不对称平衡**：对象通常偏一侧，文字占另一侧；不是居中对称的商品主视觉，也不是规则网格信息卡。

## 2. 固定色彩角色

| 角色 | 建议方向 | 用法 |
| --- | --- | --- |
| 纸面暖白 | `#FAF9F5` | 全幅底色；保持高亮、干净、无渐变 |
| 文字/曲线深棕 | `#60372F` | 所有文字、百分比和唯一连续曲线 |
| 比例轨道浅灰 | `#E8E8E5` | 三条胶囊轨道的未填充部分 |
| 材料强调色 | 从材料中提取 | 各自的比例填充；中等明度、略降饱和 |
| 阴影灰 | 中性浅灰 | 写实对象下极柔接触阴影，不形成灰色底块 |

不要把材料色平均铺到背景、文字或曲线上。固定角色不随主题漂移；变化集中在三种材料色与饮品本体。

## 3. 默认版式骨架

默认画布为约 `4:5` 竖版，可按相对坐标理解，不要求机械复制同一坐标。

- 饮品主体占画布宽 `30–38%`、高 `34–48%`，基线距底部 `5–9%`，通常偏左；杯口、吸管或装饰可进入中央留白，但不得切断信息组。
- 材料 1 是最高节点：写实材料小景位于上部偏右，宽约 `17–25%`；其文字模块落在邻近的上部偏中区域。
- 材料 2 位于中段，可在右侧或偏中位置与第一节点错开；对象宽约 `15–23%`。
- 材料 3 位于中下段偏右，必须与饮品保持一段可容纳曲线的空白；对象宽约 `14–22%`。
- 三个材料模块沿纵向递降，但不要等距排成表格。每个模块与对应食材形成一组，组与组之间由宽阔曲线隔开。
- 品牌/产品名如需出现，作为单独的一行小型锁字落在底部安全区正中央。它不与任一材料模块合并，不覆盖杯体或曲线。

为避免忠实复刻，允许每张在以下范围内变化：材料对象在模块左/右互换、饮品略向中部移动、曲线弧度和横向摆幅改变。不可改变的是纵向阅读顺序、低密度留白和主体下沉。

## 4. 材料配方模块

每个材料模块只有两层文字信息，不另加描述句、编号或装饰图标：

```text
ENGLISH NAME  中文名称
Flavor Ratio(%).  [rounded ratio bar]  NN%
```

- 英文使用全大写或小型大写的窄体单线手写无衬线；中文字形纤细、松弛、接近日常手写正体，不用毛笔书法。
- 两种语言在同一行，英文在前，中文在后，保持清楚间隔；中文不是英文下面的第三行。
- 第二行文字、比例条与百分比组成一个紧凑的横向单元。若生成模型需要轻微错层才能读清，仍保持为一个视觉层级，不扩张成卡片。
- 文字为深棕，大小层级克制。材料名最大，`Flavor Ratio(%).` 约为其 `55–70%`，百分比略大于标签但小于材料名。
- 比例轨道是浅灰圆角胶囊，长宽比约 `5.5:1`–`7:1`；材料色从左向右填充，填充长度必须与 `NN%` 一致，端部同样圆润，无描边、刻度、渐变或投影。
- 三项比例使用整数并合计 100。用户给出小数时可照录，但三条填充仍需视觉准确。

## 5. 核心连续曲线

曲线是信息结构，不是随意装饰。

- 全图只允许一条连续、无箭头、无分叉的深棕细线；在约 1200 px 宽图上视觉粗细约 `1.5–2.5 px`。
- 阅读顺序严格为：曲线先经过材料 1 的外侧近邻，再经过材料 2，再经过材料 3，最后收向饮品杯口、杯身外沿或主体附近的留白。
- 曲线用三段宽松的 S 形或长弧完成四个节点。每段曲率连续，不出现折角、心电图尖峰、闭环或规则正弦波。
- 线始终走背景空白。它不得穿过写实材料、碗碟、文字、比例条、百分比、杯体、吸管、品牌；也不从半透明物体“后面透出来”。
- 材料节点通过 `8–24 px` 视觉近邻或顺着外轮廓的切线感建立联系，不用圆点、箭头或直接刺入食材。若空间不够，优先缩小对象、移动模块或放大留白，不能牺牲避让规则。
- 曲线的具体起点、弧度、摆幅和终点必须随本张对象重新设计，禁止照描参考曲线。

## 6. 写实材料与饮品主体

### 材料小景

- 每项材料用最能被一眼认出的写实形态：完整体 + 切面、粉末 + 容器、酱体 + 原料、叶片 + 茶粉等；每组最多 1–3 个核心物件。
- 材料应像同一摄影棚拍摄：高调柔光、自然透视、真实切面与表面水分、柔软接触影。不要混合图库风格、卡通图标和 3D 塑料模型。
- 白色碗、玻璃杯等容器可以出现，但只为展示粉末/酱体，不得让三个材料都变成相同白碗。

### 饮品主体

- 有输入照片时，先尊重可见事实，再用材料逻辑精修颜色与可见颗粒；不要为了统一风格把透明杯、杯型或分层重新发明。
- 没有照片时，选择能展示配方的简单透明杯或浅色陶瓷容器。杯型是配角，液体颜色和质地才是主题。
- 主体颜色不能固定为奶白。以占比最高且有显色能力的材料决定主底色，以第二、第三材料决定分层、渐变、泡沫、碎屑或沉淀。
- 颜色混合应服从食材常识：透明果汁仍有透光；奶基会抬高明度和浑浊度；粉末、酱体与果泥可产生分层；气泡、冰块、冷凝水只在物理上合理时出现。

## 7. 材料到主体的映射

| 材料类型 | 代表色提取 | 对主体底色/透明度的影响 | 可见颗粒与层次 |
| --- | --- | --- | --- |
| 柑橘 | 果肉浅黄、橙黄或青黄，不直接取高饱和果皮绿 | 透明至半透明的淡黄/橙；奶基中变柔和奶黄 | 少量果皮屑、果肉囊、薄切片 |
| 浆果/葡萄 | 果肉玫红、莓紫、酒红，适度降饱和 | 半透明紫红或浑浊粉紫 | 果皮碎片、籽、果泥云纹 |
| 热带水果 | 杏黄、珊瑚粉、柔黄绿 | 果汁型明亮，奶基型偏柔和粉/黄 | 细果肉、籽或纤维，不全部同时出现 |
| 茶/草本/叶粉 | 茶汤琥珀、橄榄绿、抹茶绿 | 茶汤透明；研磨粉与奶基则浑浊 | 细粉悬浮、杯底轻沉淀、叶片装饰 |
| 咖啡/可可 | 焦糖棕、深可可、暖黑棕 | 深色底或清楚的深浅分层 | 可可细粉、咖啡泡沫、酱纹 |
| 乳制品/发酵乳 | 象牙白、奶油黄 | 抬高明度、增加不透明与泡沫层 | 细腻奶盖、酸奶纹理，通常无粗颗粒 |
| 坚果/谷物 | 浅米、燕麦黄、烘烤棕 | 浅米色至奶茶色，质地更稠 | 坚果碎、谷物颗粒、细腻研磨点 |
| 花卉/香料 | 花瓣本色或金黄、锈红、肉桂棕 | 低占比时只做轻微染色或香气层 | 少量花瓣、香料粉、糖边；避免过量 |
| 苏打/水/冰 | 近透明、淡青或由主风味染色 | 提高通透度和高光 | 气泡、冰块、杯壁冷凝水 |

不要机械做 RGB 平均。先判断每项材料的显色强度、透明度和物理形态，再根据比例决定谁主导底色、谁负责层次、谁只以颗粒/香气出现。

## 8. 生成前内容规格

在内部先完成以下结构；除非用户要求，不必把这张表全部展示出来。

```text
材料 1：EN / 中文 / NN% / 代表色 / 摄影形态 / 对饮品的贡献
材料 2：EN / 中文 / NN% / 代表色 / 摄影形态 / 对饮品的贡献
材料 3：EN / 中文 / NN% / 代表色 / 摄影形态 / 对饮品的贡献
合计：100%
饮品：杯型与保留特征 / 主底色 / 透明度 / 分层 / 颗粒 / 装饰
曲线：材料 1 近邻 → 材料 2 近邻 → 材料 3 近邻 → 主体终点；列出每段避让对象
品牌：精确文案或“无”
```

## 9. 原创性与验收

- 看起来是否属于同一视觉家族，却没有复制参考图的具体材料组合、杯型、曲线和物件坐标？
- 是否恰有三个材料模块，名字双语、比例合计 100、填充长度与数字一致？
- 是否只有一条连续曲线，顺序清楚，且没有碰穿任何对象或文字？
- 饮品的底色、透明度、分层和颗粒是否能由三项材料解释，而不是默认奶白？
- 是否保持高调写实摄影、深棕手写层和 55–68% 留白？
- 品牌是否只在被要求时出现，并且位于底部正中、逐字准确？
- 是否没有多余文字、箭头、卡片、边框、装饰贴纸、额外材料、logo 或水印？
