# 个性化配套图与情绪装饰

配套图不是把角色换尺寸后简单居中。它们应该从原始照片中提取个体化记忆点，再用当前表情包的插画语言重新组织。表情主图也可以加入少量装饰，但装饰必须服务情绪识别和动作节奏。

## 从原图提取设计线索

只选择1–3类最强线索，避免把原图背景全部搬进表情包：

- 角色线索：发型、耳朵、毛色、服装色块、标志性配饰或常见姿态。
- 色彩线索：一个主强调色、一个深色结构色和一个浅色背景色。
- 场景线索：超市货架、雪山轮廓、室内窗格、草地等可被几何化的空间特征。
- 道具线索：购物车、苹果、牵引背带等有个体记忆点的剪影。

不复制照片里的商标、包装文字、价签、网址或其他品牌识别元素。原图背景与角色无关时，只保留色彩或简化几何，不强行制作场景剧情。

## 配套图构图

- 表情封面：透明背景；角色占画面约55%–75%，搭配一个主题色徽章/有机色块和一个小道具；不放文字。
- 聊天面板图标：优先使用正面头部；若动物的耳、尾或低伏姿态会导致自动头部裁切出现断颈、平切边或只剩背尾，则改用高识别度的完整坐姿缩影。只留一层高对比外环或徽章，在50×50下仍能快速识别；不放文字和细小道具。
- 详情页横幅：不透明且非近白背景；一个主角姿势、最多两个次要姿势，再用场景几何和道具串成小故事；不放文字、二维码或水印。
- 赞赏引导图：上部使用感谢姿势和主题道具，下部35%–45%保持干净、对比柔和，给平台UI留空；不自行画按钮或金额。
- 赞赏致谢图：感谢姿势居中，用主题道具、爱心或星光形成收束感；装饰不超过角色的视觉权重。

## 表情主图的装饰规则

每张优先只用1–3个装饰。装饰是独立上层，不参与人脸、头身或四肢形变，动幅通常小于角色主动作。

| 表情 | 适合装饰 | 建议动法 |
|---|---|---|
| 开心 | 星光、彩屑点 | 小幅闪烁或呼吸 |
| 生气 | 怒气线、压力符号 | 短促弹出，不高频抖动 |
| 伤心 | 泪滴、小雨点 | 缓慢下落后淡出 |
| 大笑 | 笑声线、放射线 | 随身体节拍舒展 |
| 惊讶 | 短放射线、感叹形 | 随弹起节点出现 |
| 害羞 | 腮红、小心形 | 透明度缓慢呼吸 |
| 感谢 | 爱心、柔和星点 | 缓慢上浮或收拢 |
| 再见 | 挥手轨迹、小叶片 | 跟随手掌小弧线 |

装饰不能压住眼睛、嘴、手/爪、关节连接处或文字。若顶部文字已占用一侧，装饰放在另一侧或人物外轮廓下方。不加与情绪、角色或原图主题无关的随机小物。
