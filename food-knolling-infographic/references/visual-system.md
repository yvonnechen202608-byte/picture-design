# 视觉系统

## 核心印象

这套视觉不是普通菜谱页，也不是纯摄影拼贴。它把三种媒介压在同一张高调白色画布上：可触摸的真实食材、像说明书一样清楚的手绘动作、作为视觉奖励的成品摄影。阅读顺序是 `看原料 → 跟随动作 → 抵达成品`。

## 固定构图

- 画幅：默认竖版 `9:16`，可接受宽高比 `0.53–0.57`。用户指定其他比例时，仍维持自上而下的叙事顺序和右下成品重心。
- 背景：近白暖灰 `#F6F6F2` 至 `#FAFAF7`，无纹理、无渐变、无桌面边界。纯白高调但不要冷蓝。
- 安全边距：左右约画幅宽度的 `7–9%`，上下约高度的 `4–5%`。任何文字和食物不得贴边。
- 顶部菜名区：约占高度 `2.5–9%`。菜名是全图最高且最先被看见的元素，水平居中；任何栏目名、食材、点线、图标或盘器都不得高于它。中文主标题在上、英文副标题在下，整体宽度不超过画幅 `56–62%`。允许在标题两侧或上下加入 `1–2` 个极小黑色单线、短横、圆点或食材强调色符号，但装饰总面积不超过标题区的 `8%`。
- 标题下留白与栏目行：英文副行下方保留约画幅高度 `2.5–3.5%` 的干净中央留白；随后在高度约 `11–14%` 的独立栏目行左对齐放 `食材 / INGREDIENTS`。标题中心轴下方继续保持通透，栏目字标不得与标题同排或位于标题上方。
- 上部食材区：约占高度 `16–40%`。在食材栏目行下方排列 `4–6` 个写实食材，采用松散的 2×2、2×3 或不完全三列网格；大小可不同，但间距稳定、轮廓不重叠，并与栏目行保留明显空隙。
- 过渡留白：约占高度 `38–45%`。从食材区中下方引出黑色点线，先向下，再折向左，以箭头进入流程区。
- 中左流程区：左侧约占宽度 `7–30%`，从高度 `43%` 延伸到 `94%`。栏目名在流程上方；`3–5` 个图标纵向排列，图标间以点状向下箭头连接。五步流程时把图标和间距统一缩小约 `12–18%`，整列末端仍需保留至少画幅高度 `3–4%` 的暖白底部安全空隙，任何图标都不得触底或裁切。
- 右下成品区：约占宽度 `35–94%`、高度 `57–94%`。成品和盘器为最大视觉块，约占画幅宽度 `44–54%`。栏目名放在它上方或右上，不能压住盘沿。盘器必须完整留在画幅内，整圈盘沿可见，不切边、不缺角；盘器与右边、下边及相邻图标之间至少保留约画幅宽度 `4–6%` 的暖白安全空隙。
- 保留至少约 `40%` 的可见背景。中心偏右的空白是构图张力的一部分，不要用说明文字填满。

这些百分比是稳定骨架，不是像素级模板。食材轮廓、步骤数量、盘器形状和菜品方向应随主题变化，避免机械复刻。

## 食品摄影语言

- 食材使用俯视平铺或近似 `90°` 顶视角，背景清洁，边缘完整，像真实抠图而不是 3D 图标。
- 成品使用顶视或 `70–90°` 高机位；尊重用户照片原有的摆盘逻辑，不强行把侧视食物扭成俯视。
- 用户照片中的每一种可见蔬菜、配料、点缀、酱汁和容器都属于主体身份。抠图与清理只去除背景、平台文字、logo、水印和无关道具；不得因文字菜谱省略某项而删除照片里真实可见的食物内容，也不得把它替换成更“理想”的版本。
- 光线来自左上方的大型柔光源。阴影轻、短、偏右下，灰度中性，透明度低；所有对象的光向必须一致。
- 保留真实质感：肉类纤维与焦化、蔬菜水分、面包孔洞、酱汁黏度、米粒或面条的独立结构、陶瓷盘细微斑点。避免塑料般光滑和过饱和 HDR。
- 盘器优先暖白、米白或浅灰手作陶瓷。道具仅在能识别菜品时出现一个，例如筷子或小勺；不要布置桌布、砧板和散落餐具。

## 流程插画语言

- 黑色或近黑 `#171717` 单线手绘图标，圆头圆角，线条略有人工抖动但仍干净专业。
- 在约 800 px 宽画布上，主体描边视觉上相当于 `2–4 px`；缩放时保持细而清楚，不能像粗体贴纸。
- 图标以手、刀、锅、火、搅拌、折叠、组装、计时等单一动作表达步骤。每个图标只传达一件事，轮廓优先于细节。
- 允许在一个关键食材或动作上加入来自菜品的自然强调色，但彩色面积不超过流程插画总面积的 `15%`。其余保持黑白。
- 点线由均匀小圆点构成，箭头尖端简洁。连线必须走背景空白，不穿过食材、图标、文字或成品。
- 同一张图内不要混用照片式流程图、实心扁平图标、工程 CAD 线稿、儿童蜡笔画或厚重漫画描边。

## 字体与字标

- 固定栏目名：`食材 / INGREDIENTS`、`步骤 / PROCESS`、`成品 / FINAL DISH`。
- 中文在前、英文在后；同一行优先，空间不足时可两行堆叠，但必须保持为一个紧凑字标。不要只保留英文。
- 菜名必须出现且中英双语，并位于全图最上方：第一行是完整中文菜名，第二行是自然、简短、准确的英文译名并使用 uppercase。菜名不加 `菜名 / DISH` 前缀，不使用斜杠把两种语言挤在同一行。
- 菜名中文主标题约为栏目名字高的 `1.45–1.8` 倍，medium/semibold，形成明确但不压迫的一级标题；英文副标题约为中文标题的 `42–50%`，增加少量字距。两行居中对齐为一个整体，宽度不超过画幅 `56–62%`；长菜名优先适度缩小字号与字距以保持两行，不挤压左右安全边距。标题下面必须有清楚留白，`食材 / INGREDIENTS` 另起一行并低于标题。
- 菜名翻译优先保留菜系与核心食材含义；用户提供译名时逐字使用。没有标准译名时选清楚易懂的描述性英语，不虚构产地、品牌或卖点。
- 中文字体气质：现代中性黑体、窄而利落、字面清楚，可参考思源黑体或苹方的中等字重；不要书法、圆体、宋体或复古印刷体。
- 英文字体气质：瑞士国际主义无衬线，uppercase，medium/semibold，轻微正字距；可参考 Helvetica/Inter/Neue Haas Grotesk 的中性质感，但不要求复刻特定字库。
- 字色统一为 `#171717`。字号克制，栏目名高度约为画幅高度的 `1.6–2.2%`，绝不与成品争夺视觉焦点。
- 每个字标带一个短粗上横杠和一条较细下划线。上杠约为字标宽度的 `18–28%`，下划线约等于或略短于字标宽度；线与字保持透气间距。
- 除双语菜名、栏目名和必要步骤短注外，不增加正文。若用户要求更多可见文字，每个独立信息必须是 `中文 / ENGLISH` 配对。

## 配色规律

- 基础色只有暖白背景与近黑信息线。
- 彩色来自本张食材和成品的天然颜色，不人为套一组与食物无关的品牌色。
- 保持高明度、自然饱和：叶菜绿、番茄红、蛋黄黄、鲑鱼橙、烘烤金棕等可作为局部强调；整张图通常不超过 `3–5` 个主要天然色族。
- 阴影使用低饱和中性灰；盘器避免纯蓝白。禁止霓虹色、重紫色阴影、复古棕黄滤镜和大面积彩色块。

## 内容映射

- 食材：优先选择一眼可识别且决定菜品外观的 `4–6` 项。主料占更大面积，香草、香料和酱料形成小组，不把十几种调料逐一摊开。
- 流程：通常压缩为 `3–4` 个关键动作；用户明确给出五个不可合并的步骤时保留 `5` 个。示例逻辑是准备/切配 → 加热/烹调 → 组合/调味 → 计时/完成；不要照搬示例图标，按本菜重新设计动作。优先缩小图标与间距，不以裁切或删步解决空间不足。
- 成品：必须是视觉终点和最大彩色焦点。若使用用户照片，身份保真优先于理想化重摆；照片里出现的蔬菜、配料与点缀必须完整保留，即使书面菜谱没有逐项列出。
- 文案：中英双语菜名与三个栏目名都必须出现。没有事实依据时，不展示份量、温度、分钟数或营养数值。

## 原创与禁区

- 参考图只提供抽象语法。除非用户主题本身就是该菜，不复用其中的牛排、汉堡、寿司、虾面或牛油果吐司；即使主题相同，也要改变食材姿态、盘器、图标动作与空间节奏。
- 不复制参考图的逐像素坐标、同一盘器、同一切片角度、相同图标轮廓或装饰星标。
- 不做：白色卡片嵌套、分栏边框、彩色色块标题、3D 流程图标、照片式人物手、整页文字、复杂数据图、写实厨房场景、过强投影、镜面反射、漂浮颗粒、水印或生成器签名。

## 质量门槛

成图必须同时满足：菜名是全图最高元素、字号相对醒目且中英文完整；标题小装饰克制；`食材 / INGREDIENTS` 在标题下方另起一行；一眼读出食材、步骤、成品三段叙事；各区留白舒展；食材与成品写实；原照片所有可见食物内容均被保留；成品盘沿完整无裁切且四周有安全空隙；流程图标同一笔触；三处栏目名全部中英双语且无乱码；点线不穿物；菜品身份正确；没有参考图的具体内容残留。
