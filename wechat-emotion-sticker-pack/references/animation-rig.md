# 姿态保持动画绑定

自然动画首先要保持角色结构稳定。每张母图都要标记面部、身体、承重点和主要肢体，再由 `scripts/pose_preserving_animation.py` 生成 `pose-preserving-intact-silhouette-v10` 动画：脸、头、颈和躯干默认作为一个等比刚性整体，绑定点用于确定运动中心、小型五官覆盖和安全的肢体/尾巴链，而不是用来拖拽五官或揉捏身体。

## 绑定文件

绑定文件使用 JSON，坐标相对于“母图可见主体的 alpha 包围盒”，左上角为 `(0, 0)`，右下角为 `(1, 1)`：

```json
{
  "version": 2,
  "animation_model": "pose-preserving-intact-silhouette-v10",
  "coordinate_space": "subject-bbox-normalized",
  "expressions": {
    "01": {
      "motion_policy": {"forepaws": "grounded-intact-silhouette"},
      "points": {
        "head": {"x": 0.50, "y": 0.30, "r": 0.30},
        "left_eye": {"x": 0.41, "y": 0.32, "r": 0.065},
        "right_eye": {"x": 0.59, "y": 0.32, "r": 0.065},
        "mouth": {"x": 0.50, "y": 0.45, "r": 0.085},
        "left_ear": {"x": 0.28, "y": 0.10, "r": 0.14},
        "right_ear": {"x": 0.72, "y": 0.10, "r": 0.14},
        "left_paw": {"x": 0.34, "y": 0.62, "r": 0.14},
        "left_wrist": {"x": 0.36, "y": 0.56, "r": 0.12},
        "left_shoulder": {"x": 0.39, "y": 0.52, "r": 0.14},
        "right_paw": {"x": 0.66, "y": 0.62, "r": 0.14},
        "body": {"x": 0.50, "y": 0.70, "r": 0.30},
        "left_foot": {"x": 0.38, "y": 0.90, "r": 0.13},
        "right_foot": {"x": 0.62, "y": 0.90, "r": 0.13},
        "tail_base": {"x": 0.78, "y": 0.76, "r": 0.15},
        "tail_mid": {"x": 0.86, "y": 0.50, "r": 0.15},
        "tail": {"x": 0.87, "y": 0.22, "r": 0.15}
      },
      "disabled": ["tail"]
    }
  }
}
```

`r` 是部位范围提示，相对于主体包围盒的较长边。v10不会根据这些半径叠加高斯/RBF拉扯；眼睛、嘴、头和身体的范围用于质检和定位部分上眼睑、泪滴、腮红等小型独立覆盖。独立胶囊蒙版只用于轮廓清楚且10倍逐帧放大无缝的肢体；黑色、深色或低纹理动物的关节难以可靠分割时，在对应表情加入 `motion_policy`，选择不切分主体轮廓的整体动作。尾巴若需要独立细颤，必须同时提供 `tail_base`、`tail_mid`、`tail`，只让尾中段以外的远端绕 `tail_mid` 小角度转动。眼睛通常取 `0.05–0.08`，嘴取 `0.07–0.11`，手/爪和腕取 `0.10–0.16`。

当前可用的完整轮廓策略：猫玩耍俯身使用 `{"forepaws": "grounded-intact-silhouette"}`；深色猫抬爪告别使用 `{"raised_forelimb": "whole-body-sway-intact-silhouette"}`。这两种策略都禁止创建肢体切片，动作来自整体重心或肩背小幅摆动。

## 标注要求

- `head` 放在头部视觉中心；眼睛与嘴放在可见器官中心，不按默认对称位置猜测。左右瞳孔因头部倾斜而高度不同时，分别记录各自纵坐标，禁止为了对称强制共用同一个 `y`。
- `left_*` 和 `right_*` 按画面观察者左右标注，并在一套表情中保持一致。
- 前爪标在动作末端，脚标在承重点；尾巴依次标记尾根 `tail_base`、弯曲中段 `tail_mid` 和可见尾尖 `tail`。挥手额外标出同侧 `wrist` 与 `shoulder`。只有肩到手/爪之间轮廓连续且与脸身有明显负空间时，才启用刚性手臂链；不可见或无法安全分离的部位放入 `disabled`。
- 伤心表情若有泪珠，补充 `left_tear`、`right_tear`；没有泪珠时禁用它们。
- 至少标出 `head`、两眼、嘴、两耳、身体和两个主要动作肢体。复杂姿势必须逐图标注，不能让8张图共用一套默认坐标。
- 用母图的透明包围盒换算坐标，不要按完整画布换算。

## 情绪编舞

| 语义 | 五官动作 | 头耳动作 | 身体与四肢动作 |
|---|---|---|---|
| 开心 | 约180ms的部分微眨：下压—峰值—回弹3个连续帧；最大覆盖32%–44%，始终保留圆润瞳孔下缘 | 整体轻快上提并微侧倾 | 人物举手可使用安全腕链；猫玩耍俯身时前爪保持落地和完整轮廓，用肩背轻弹与前后重心表达开心 |
| 生气 | 聚焦式部分眨眼，保留皱眉绷嘴 | 整体短促左右摆动 | 猫采用小幅重心换边；不揉捏拳头或脚 |
| 伤心 | 母图保持垂眼与泪痕，末端尖滴真正下落16–20px | 整体缓慢下沉、低头感 | 不做欢快回弹，不拉长原泪痕 |
| 大笑 | 母图保持笑口，闭眼眼角轻微脉冲 | 整体左右后仰感摆动 | 猫侧躺时做腹部随呼吸轻弹，爪与躯干保持刚性关系 |
| 惊讶 | 母图保持睁眼张口 | 整体快速等比弹大后复位 | 有显眼尾巴时稳定尾根和尾中段，仅让尾梢细颤 |
| 害羞 | 慢速部分眨眼，红晕位于眼外下方 | 整体小幅侧摆 | 猫揣手趴卧时增加轻呼吸；爪与脸重叠时不分层拉动 |
| 感谢 | 亲近式慢眨 | 坐姿歪头并轻微前倾 | 爪、肩、躯干保持固定比例 |
| 再见 | 母图保持微笑，不额外眨眼 | 猫以落地爪或臀部为支点做肩背轻摆 | 深色猫优先保持完整主体轮廓，让抬爪随身体走小弧线；只有整链轮廓清晰且放大无缝时才分离旋转，轨迹线置于主体后方并被主体遮挡 |

每个循环首尾应回到同一中性姿态。优先生成16个节拍帧，GIF压缩后仍保留至少12帧。动作幅度以240×240成图中的1–4px为主，整体转角通常为0.2–1.2度，等比缩放通常为0.4%–1.5%。禁止眼睛、嘴、脸、头或躯干使用非等比缩放；不要为追求显眼而添加高频抖动。

闭眼、泪滴、腮红、表情线和少量情绪装饰必须在整体姿态变换后添加，并使用变换后的绑定点定位。覆盖层不修改原始脸型或身体形状；装饰不压住文字、五官、关节和主动作轮廓。开心只做一次快速部分微眨：使用从眼上方与眼下方采样的双色皮肤/毛色渐变，在约3个连续帧中完成下压、峰值和回弹；下沿必须是中心稍低、两端稍高的柔和弧面，最大覆盖通常为32%–44%，峰值仍保留两只瞳孔圆润的下缘。不要完全抹掉眼睛，不画闭眼横线，也不添加横向阴影带。母图已有泪痕时不在眼下再画大圆泪泡，只在末端加半径约1.5–2.4px、连续可见至少5帧、下落16–20px的无白边小型尖滴；害羞腮红用眼外下方的低透明短线，不用跨脸横带。

## 质检

导出前检查逐帧预览或联系表：

- 面部区域与身体/肢体区域应有可感知的整体位姿变化，但不要求五官独立形变。
- 跨帧比较眼距、脸宽高比、下颌线、颈肩宽度和躯干比例；除统一等比缩放外应保持不变。
- 脚站立时保持承重点稳定；鞠躬和挥爪必须符合关节与重心方向。
- 五官不能滑离脸部，耳朵与爪不能像独立贴片，刚性肢体蒙版边缘不能出现破洞、接缝或重影。
- 对启用独立摆动的肢体，额外放大检查肩—腕—手：近端袖管alpha必须连续，腕口重叠区必须每帧相交，不允许白/透明弯月裂缝。
- 即使没有启用独立肢体链，也要对语义主爪运行10倍放大联系表；高亮星光、挥手轨迹、描边或调色板噪点都不得穿过爪面。若出现疑似裂缝，先关闭局部切分并把装饰移到轮廓外，不用更宽蒙版掩盖问题。
- 对尾巴和泪滴运行 `render_feature_review.py`：尾根/尾中段不动且连续，尾梢位移清楚但克制；泪滴至少跨5帧持续向下移动，不能原地闪烁。
- 对眼—嘴组成的脸部核心区计算每帧alpha覆盖率；出现新增透明缝、横线或局部断层时直接判定为不合格。
- 首尾帧无跳切，循环节奏符合情绪；伤心和感谢更慢，生气、惊讶更快。
- 先保证自然性，再在不破坏动作的前提下降色；正式结果保留至少12个可区分帧。
