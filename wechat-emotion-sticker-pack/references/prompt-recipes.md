# 生图提示词配方

这些配方用于组织 `image_gen` 请求。把方括号替换为本次输入事实；不确定的身份特征不要猜。

## 角色基准图

```text
将输入照片中的[人物/动物]转译为原创的[所选风格]微信表情角色。
身份锁：[5–8个可核对特征]。
角色正面略微三分之二视角，完整头部和身体，姿态自然，神情中性友好。
保持身份锁、原有毛色/肤色、发型、脸型、耳形、花纹和标志性配饰，不添加新角色。
正方形构图，主体居中但不僵硬，四周保留12%安全区。
真实alpha透明背景；不要白底、棋盘格、场景、地面、投影、边框、文字、签名或水印。
输出单张独立PNG，不要网格，不要角色设定表。
```

## 情绪母图通用骨架

```text
以输入照片和角色基准图为同一角色参考，生成第[序号]张独立微信表情母图。
身份锁：[完整复述身份锁]。
风格锁：[粘贴所选风格的关键规则]。
语义：[情绪名]。
表情与动作：[对应动作描述]。
角色的脸、毛色/肤色、发型、耳形、花纹、服装和配饰必须与角色基准图一致。
单一完整角色，动作轮廓清楚，四周保留10–15%安全区，适合缩小到240×240观看。
真实alpha透明背景；不要场景、地面、投影、矩形底、棋盘格、文字、边框、签名或水印。
输出单张正方形独立PNG，不要网格或sprite sheet。
```

## 默认8种表情与动作

下表中的人物动作只表达聊天意图。若主体是动物，必须先按物种自然形态改写，不能把动物直立成人或把爪生成五指手。猫的推荐转译为：开心用玩耍俯身，生气用四足低伏警戒，伤心用垂耳蜷坐，大笑用侧躺翻滚，惊讶用四足弓背，害羞用揣手趴卧，感谢用歪头坐姿与慢眨，再见用三足支撑下的单前爪小幅抬起。

| 编号 | 含义 | 生图动作 | 五官与肢体编舞 |
|---:|---|---|---|
| 01 | 开心 | 明亮微笑；人物可抬手，动物采用该物种的玩耍邀请或舒展姿态 | 眨眼与笑口开合；耳尾与身体做轻快回弹，承重关系保持自然 |
| 02 | 生气 | 眉眼收紧，握拳或跺爪，身体前倾，可有极少量原创怒气符号 | 眼睛压窄、头部短促前压；一爪跺地，另一爪与身体克制颤动 |
| 03 | 伤心 | 眼泪、肩膀或耳朵下垂，身体微蜷 | 慢眨眼、嘴角收拢、泪珠下滑；低头垂耳、身体内收 |
| 04 | 大笑 | 闭眼大笑，身体后仰或抱腹，轮廓与01明显不同 | 笑口张合、头部后仰；抱腹双爪、脚与尾巴错相摆动 |
| 05 | 惊讶 | 睁大眼睛、张嘴，双手或前爪展开，身体瞬间绷直 | 眼嘴同步放大、双耳竖起；双爪外弹后身体回落 |
| 06 | 害羞 | 脸颊泛红、目光略躲闪，双手或前爪靠近身体 | 目光轻移并短眨眼；头部侧摆、双爪向胸口靠拢 |
| 07 | 感谢 | 人物可合掌或鞠躬；动物使用慢眨、歪头、亲昵坐姿或贴近动作 | 头耳同步轻动；四肢保持自然支撑，尾巴小幅回应 |
| 08 | 再见 | 人物挥手；动物在稳定支撑下自然抬起单只前爪 | 笑口轻动；仅抬起爪的远端画小弧，其余爪与尾巴稳定重心 |

母图保持无字，动态文字在打包阶段单独叠加，以免生图模型产生错字。默认文案与文字动画规则见 [dynamic-text.md](dynamic-text.md)。

## 单变量修正模板

- 透明度失败：`只修背景：保留角色、表情、姿势和画风完全不变，移除所有背景与投影，输出真实alpha透明PNG。`
- 身份漂移：`只修身份：按身份锁恢复[具体特征]，其余构图、动作、情绪和透明背景不变。`
- 动作不清：`只修动作：把[动作]放大到缩小后仍清楚，角色身份、画风、配色和背景不变。`
- 风格漂移：`只修画风：恢复[预设中的3条关键规则]，角色身份、动作、构图和透明背景不变。`
