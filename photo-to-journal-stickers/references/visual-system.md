# 视觉系统：暖调叙事手帐素材

这套视觉不是对某一张参考图的复刻，而是从一组“现场照片 → 对象图鉴/贴纸素材”的样例中提炼出的原创规则。

## 1. 核心气质

- 像旅行者把一天里最值得记住的东西重新画进手帐：温暖、安静、略带旧时光感，但不脏、不灰败。
- 介于编辑插画、植物/器物图鉴、旧绘本与轻水粉之间；写实结构与朴素造型并存。
- 物件有真实重量和材质，却不是照片复制。细节经过选择性概括，边缘保留轻微手绘不齐。
- 叙事来自“选了什么”和“尺度怎么排”，而不是堆背景、加口号或制造戏剧特效。

## 2. 固定色彩骨架

以暖象牙纸、蜂蜜木色和深棕墨色为底，橄榄绿/森林绿与灰蓝/旧青绿负责平衡，陶土橙或番茄红只做小面积点睛。

| 角色 | 建议色 | 用法 |
| --- | --- | --- |
| 暖象牙 | `#F3EBDD` | 高光、浅色物件、展示页底色 |
| 蜂蜜赭 | `#C48A3A` | 木器、暖光、主调连接色 |
| 陶土橙 | `#B85D35` | 约 5–10% 的节奏点 |
| 芥末黄 | `#D2A23C` | 花、果实、局部金色感 |
| 橄榄绿 | `#6D7440` | 植物、阴影中间色 |
| 森林绿 | `#344A38` | 深色锚点，避免纯黑 |
| 灰蓝绿 | `#5F8080` | 冷暖平衡、陶釉、远景 |
| 雾蓝灰 | `#93A3A3` | 雪、玻璃、金属反光 |
| 墨棕 | `#3D3027` | 轮廓、最深阴影、少量文字 |

色彩关系比十六进制值更重要：整体中低饱和；暖色约占六成，冷色约占两成，中性色约占两成；纯红、纯蓝、纯黑和纯白都要避免大面积出现。即使原照片颜色偏冷，也用蜂蜜赭与象牙高光把画面拉回温暖；但不要抹掉主题本身具有辨识度的颜色。

## 3. 画法与材质

- 媒介感：不透明水彩/水粉打底，叠加干刷、短排线和轻微纸纤维；局部可有彩铅或细墨线收边。
- 造型：以大色块建立清楚剪影，再用少量结构线和高光描述材质。避免逐像素描摹。
- 轮廓：深棕、墨绿或物体自身深色；线条不必处处闭合，粗细略有变化。
- 明暗：两到三级即可。阴影偏暖棕或灰绿，高光偏奶油色；不要使用锐利摄影反光、强 HDR 或大片渐变光晕。
- 表面：木头、陶器、织物、金属、树叶、毛发都要有各自的简化纹理，但颗粒统一、密度克制。
- 边缘：干净可剪贴，仍保留轻微手绘毛边；不能出现白色 halo、半透明脏边或残留背景碎屑。

## 4. 元素选择规则

先找场景的“名词”，再找场景的“记忆”。

1. **主角**：决定地点或事件的对象，例如山体、人物姿态、建筑、炉火、特殊摆件。
2. **支撑物**：补充生活方式与环境，例如桌椅、灯、茶具、路牌、树篱、器物组合。
3. **点缀物**：形成节奏的微小线索，例如松果、钥匙、花束、杯子、枝条。

选择时优先：独特轮廓 > 叙事作用 > 材质差异 > 色彩点睛。不要把同类物件全部画出；成组对象只有在“组合关系”本身有意义时才作为一个贴纸，例如一套茶具或一桌两椅。

## 5. 单个贴纸构图

- 采用正面、轻微俯视或轻微三分之四视角，尽量复用原物最有辨识度的观察角度。
- 主体视觉占画布约 76–84%，四周保留约 8–12% 透明安全区。
- 长条物、圆形物、成组物保持自然方向，不为了填满正方形而拉伸。
- 保留完整轮廓，不裁切枝叶、尾巴、把手、屋檐、吊绳等结构性末端。
- 默认无地面、无投影、无环境背景。确实需要支撑结构时，只保留与主体物理相连且能解释形状的最小部分。

## 6. 成套构图

- 层级清楚：主角最大，支撑物中等，点缀物最小；尺度差至少有 1.5–2 倍变化。
- 位置松散但有秩序，避免等宽等高九宫格。可以三列起步，再通过错位与大小差制造编辑感。
- 展示页 55–70% 是暖白留白；对象之间保持呼吸，不重叠关键轮廓。
- 没有卡片边框、阴影面板或 UI 标签。若需要裁切提示，可用极细浅灰轮廓，但默认关闭。

## 7. 字体气质

字体只服务于展示页、标题页或用户明确要求的文字贴纸。

- 主标题：纤细、高对比、略窄的 editorial serif，大小克制、字距偏松，可使用全大写拉丁字母或短中文标题。
- 次级说明：朴素的人文无衬线或轻微手写感批注；行距宽、颜色用墨棕或灰蓝绿。
- 排版：文字是空气中的小声旁注，不是海报口号。避免粗黑体、圆润可爱字体、霓虹字、阴影字和满版大标题。
- 文字准确性优先。没有用户提供的精确文案时，不主动生成虚构店名、品牌、数字或外语装饰。

## 8. 照片类型的转译

- **街景/旅行**：提取地标、典型建筑、路牌/镜子、植物、动物或人物动作；删除电线等视觉噪声，除非它是场景记忆点。
- **室内/餐桌**：优先功能组合与温暖材质，如炉、灯、桌椅、器皿；将杂乱小物合并成一两个可读组合。
- **商店/市集**：挑选最具地域和手工特征的器物；重复货品只保留一个代表或一个小组合。
- **首饰/收藏**：保持轮廓、镶嵌结构、时代感和材料差异；省略价格签、编号和展示布。
- **人物/宠物**：保留姿态、服装/毛色块与标志性配件；面部以温和概括为主，不把人物改成夸张大眼卡通。
- **自然景物**：把大场景提炼成标志性剪影，并另取 1–3 个局部物种或季节线索；不要把整张风景直接缩成一个矩形贴纸。

## 9. 原创性与禁区

- 继承的是色温、媒介、留白、层级和编辑气质，不是参考图中的具体对象、摆放关系、花纹或文字。
- 禁止把输入照片直接滤镜化、描边后伪装成插画，或把参考图中的现成贴纸重画一遍。
- 避免：摄影感、塑料 3D、硬边矢量、动漫赛璐璐、厚白边贴纸、鲜艳糖果色、泛黄噪点滤镜、过度精密写实、重复纹理、文字乱码。
